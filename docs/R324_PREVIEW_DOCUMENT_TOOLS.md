# R324 integration — standalone preview document tools

Companion to the consolidated codec commit 8296ba23feec0c1e7ca129553151b1a8be6b613e. The independent Windows GL1.1 desktop demo now exposes Ctrl+Shift+S (export) and Ctrl+Shift+O (import) through explicit file selection; the shortcuts are below the existing text, bind, dropdown and confirmation ownership gates. Neither the launcher nor injected/native game routes call the document API. Import resets transient preview gestures, preserves the independent native profile bridge and allow-input policy, and adjusts preview dimensions. Existing startup profile files are unchanged; no automatic save/import or profile-modal callback behavior is added. The application still rejects external process arguments.

A cross-platform console tool supports create, inspect and canonical copy of local preview documents. Inspect prints summary counts and catalog identity without names or entered text. Create/copy reject an output already present when checked; this is not exclusive cross-process creation. CLI paths follow the platform narrow argument encoding. Explicit Windows file dialogs use native Unicode paths. The CLI CTest verifies the default document, canonical copy identity, failed overwrite preservation, invalid input and absent files.

The standalone GUI persists recovered preview data, not the separate ClientSettings profile; the latter remains authoritative for its existing mapped controls. This does not establish native Slinky profile format parity or operational game modules. Windows dialog interactions need manual testing; CI covers build and CLI/codec tests. No merge.
