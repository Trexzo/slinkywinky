# R326 — consolidated UTF-8 presentation pipeline

Base 78c3405c0d7f96d1a000c434383c495da52643ca, R325 13/13 CI passed. Introduced one allocation-free scalar codec for strict UTF-8 prefix decoding, encoding, bounded text validation, and bounded display iteration. Existing text editing and document semantics are unchanged; Windows preview UTF-16 conversion delegates to the shared encoder. The GDI system font retains mandatory ASCII and optionally caches Latin-1 characters if provided by the local font. Unsupported valid scalars become a single question mark rather than one per byte; malformed bytes consume one byte. Fallback bitmap rendering and measurement share an 80-scalar cap. This is not Unicode shaping, grapheme support, bidirectional layout or original font parity. The wire format and catalog fingerprint remain unchanged.

New CTest enumerates all 1,114,112 Unicode code-point candidates, checking 1,111,999 admitted scalar encode/decode round trips and truncations, rejects malformed sequences, and exercises bounded display/fallback. Windows WGL assertions check supplementary-character replacement width, Latin-1 measurement/drawing and GL-state preservation. No module behavior or loader changes. Local full build not performed; CI required.
