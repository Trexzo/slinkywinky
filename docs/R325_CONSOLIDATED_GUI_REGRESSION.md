# R325 — Windows font regression and whole-catalog document verification

Base bfd7763c20af3ce2eb80cde62b766ea7e9cdbf22. R324's Linux Debug/Release/sanitizer tests passed. Windows Debug, Release and standalone-loader jobs failed the existing isolated WGL system-text measurement assertion. R323 introduced a zero-byte raster rejection when GDI reports nonzero black-box dimensions, a plausible regression for blank outlines. R325 explicitly preserves the advance of zero-byte glyphs, normalizes their raster dimensions to zero and validates the actual second GDI call's returned coverage. The original Windows measurement assertion remains intact; additional assertions cover all 95 printable ASCII advances, whitespace and GL state preservation. The platform-independent helper tests all 81-by-81 dimensions for zero-byte outlines, and exact/short/extra raster sizes for positive dimensions. No font assets introduced.

The R324 document fixture now checks invalid IDs, wrong value types and duplicate records individually across all 373 serializable callsites, tests eight dedicated mode combinations, and runs 2,048 deterministic checksum-recomputed binary mutations. Every admitted mutation must pass validation, canonical re-encoding and restoration, while both accepted and rejected cases must be observed. The document schema and existing compatibility fingerprint are unchanged.

These are offline GUI and persistence regression improvements, not gameplay implementation. No change to native loader or game hooks. Root cause of the Windows failure is inferred from the code difference; CI must confirm the correction. Local full build not performed. Both PRs remain draft.
